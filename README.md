# Kapkin Viewer

Экран мастера для настольных ролевых игр. Мастер выводит окно на второй монитор
или телевизор, а игроки видят карту локации, токены персонажей, сетку, пометки
кистью и броски кубиков.

Приложение работает целиком в браузере: сервера нет, всё лежит в хранилище
браузера. Собранная версия живёт на GitHub Pages.

## Запуск

```bash
npm install
npm run dev     # http://localhost:3000
```

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Дев-сервер на порту 3000 |
| `npm run build` | Проверка типов (`tsc`) и продакшен-сборка |
| `npm run lint` | ESLint, падает на любом предупреждении |
| `npm test` | Тесты (Vitest); `npm run test:watch` — в режиме наблюдения |
| `npm run deploy` | Сборка и публикация на GitHub Pages |

## Что умеет

**Картинки.** Перетащите изображение в окно — оно ляжет на стол. Токены двигаются
мышью и масштабируются колесом. Три вида картинок: обычный токен, фон локации
(один на локацию) и боевая карта во весь экран.

**Приближение.** `Ctrl` + колесо приближает карту к точке под курсором, `Ctrl` +
левая кнопка возит её, `Z` возвращает целиком. Браузерный зум по `Ctrl` + колесо
при этом не срабатывает — приближается сцена, а не страница. Вместе с картой едут и
масштабируются токены, боевая карта и рисунок кистью; сетка, кубики и панели
остаются на месте. Приближенный вид — часть локации: у каждой он свой и
переживает перезагрузку. Токен при этом может уехать за край экрана, но не за
край карты.

**Любой экран.** Карта показывается целиком и в своих пропорциях: если они не
совпадают с пропорциями окна, по краям остаются поля с мягким градиентом. Всё,
что стоит на карте, помнит своё место долями от неё, а не пикселями, — поэтому
окно можно растянуть или перенести на телевизор другого разрешения, и токены,
боевая карта и пометки кистью останутся на тех же местах карты. Сцены, собранные
в старых версиях, переводятся на новые координаты сами, при первом открытии.

**Здоровье.** Стрелки ↑ и ↓ меняют счётчик у последнего выбранного токена. На нуле
токен становится полупрозрачным.

**Локации.** Список локаций — отдельная панель. Переключение полностью меняет
сцену: свои картинки, свой фон, свой рисунок. Всё сохраняется само и переживает
перезагрузку.

**Сохранение игры.** В панели локаций три кнопки внизу списка. «Скачать»
складывает все локации со всеми картинками, фонами и рисунками в один файл
`.kvgame`; кнопка в строке локации скачивает её одну. «Загрузить» открывает игру
из файла начисто — текущие локации при этом удаляются, поэтому приложение
переспросит. «Добавить» подмешивает локации из файла к тем, что уже есть: так
можно перенести пару карт из соседней игры или дважды загрузить один и тот же
файл, получив независимые копии.

**Рисование.** Кисть и ластик поверх сцены: три цвета, размер и прозрачность.
Рисунок принадлежит локации и сохраняется вместе с ней. Пометки живут на карте:
они едут и растут вместе с ней и остаются чёткими на любом приближении — даже
если приблизиться к штриху, поставленному на общем плане.

**Кубики.** d4, d6, d8, d10, d12, d20 с анимацией броска.

**Потерянный курсор.** Резко поводите мышью из стороны в сторону — вокруг
курсора разрастётся ореол и сам погаснет через секунду. Пока кнопка мыши
зажата, ореол молчит: это перетаскивание токена или штрих кистью. `O` меняет
вид ореола: строгое кольцо или радужное.

## Горячие клавиши

Все буквенные клавиши работают в обеих раскладках — переключать язык не нужно.
Пока курсор стоит в поле ввода, срабатывают только `PageDown` и `F1`.
`F1` открывает эту же справку прямо в приложении.

| Клавиша | Действие |
| --- | --- |
| `PageDown` | Список локаций |
| `B` / `И` | Режим загрузки фона |
| `L` / `Д` | Режим боевой карты |
| `M` / `Ь` | Сетка |
| `'` / `Э` | Эйдос |
| `D` / `В` | Панель кисти |
| `O` / `Щ` | Вид ореола курсора |
| `Z` / `Я` | Показать карту целиком |
| `1`–`6` | Добавить кубик (d4, d6, d8, d10, d12, d20) |
| `Пробел` | Перебросить все кубики |
| `↑` / `↓` | Здоровье активного токена |
| `F1` | Справка по горячим клавишам |

Мышь: левая кнопка — тащить, правая — удалить, средняя — дублировать,
колесо — масштаб токена. `Ctrl` + колесо — масштаб сцены, `Ctrl` + левая
кнопка — перемещение сцены.

## Как устроено

React 19 + TypeScript + Vite. Состояние — два контекста (`LayerProvider`,
`DrawProvider`), хранилище двухуровневое: метаданные в `localStorage`, сами
картинки и рисунок — блобами в IndexedDB.

Подробности для разработки — в [CLAUDE.md](CLAUDE.md).
