# Горячие клавиши

Все клавиши объявлены в одном месте — `src/hooks/hotkeys/keymap.ts`, — а
обработчики вешаются через `useHotkeys`. Новых слушателей `keydown` на `document`
в компонентах быть не должно: правила ниже живут внутри хука, и в обход хука они
не применятся.

## Два правила, которые легко забыть

**Обе раскладки.** Мастер за столом не переключает язык ради горячей клавиши,
поэтому у буквенного хоткея всегда две клавиши: `['b', 'и']`, `['m', 'ь']`,
`["'", 'э']`. Это проверяется тестом в `useHotkeys.test.tsx` — забыть не даст, но
лучше не доводить до красного прогона.

**Поле ввода.** Пока мастер печатает имя локации, хоткеи молчат: иначе буквы
переключали бы режимы, а пробел кидал кубики. Гейт — флаг `isInputActive` из
`LayerProvider`. Исключение объявляется явно, через `worksInInput: true`; сейчас
оно одно — `PageDown`, который открывает список локаций.

## Как добавить

1. Опишите клавишу в `HOTKEYS` (`src/hooks/hotkeys/keymap.ts`): клавиши **в
   нижнем регистре**, `description` для таблицы в README, `worksInInput` — только
   если действие осмысленно при наборе текста.
2. Повесьте обработчик там, где живёт состояние:

   ```ts
   useHotkeys({
     myAction: () => setSomething((prev) => !prev),
   });
   ```

   Если действие зависит от нажатой клавиши (как выбор кубика), обработчик
   получает событие: `addDice: (event) => DICE_BY_KEY[event.key]`.
3. Добавьте строку в таблицу горячих клавиш в `README.md`.

## Занятые клавиши

Смотрите `HOTKEYS` — это единственный источник правды; тест не даст назначить
одну клавишу двум действиям. На момент написания заняты: `PageDown`, `b`/`и`,
`l`/`д`, `m`/`ь`, `'`/`э`, `d`/`в`, `1`–`6`, пробел, `↑`, `↓`.

Выбирая клавишу, помните, что мастер работает одной рукой, не глядя на
клавиатуру: держитесь левой половины и не занимайте клавиши, соседние с уже
занятыми по смыслу.

## Если клавиша не срабатывает

Проверьте по порядку:

1. Клавиша записана в нижнем регистре? Хук сравнивает с `event.key.toLowerCase()`.
2. Нужная раскладка объявлена? В русской раскладке `event.key` — это `и`, а не `b`.
3. Фокус не в поле ввода? Проверьте `isInputActive` и нужен ли `worksInInput`.
4. Имя специальной клавиши совпадает с тем, что даёт браузер? Это `pagedown`,
   `arrowup`, `arrowdown`, пробел — это `' '`.
5. Компонент с `useHotkeys` вообще смонтирован? Панели рендерятся условно.
