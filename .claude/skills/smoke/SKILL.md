# Ручная проверка

Автотесты покрывают логику: карту клавиш, ключи хранилища, реестр object URL. Всё
остальное в этом приложении — мышь, canvas и реальный IndexedDB, и проверяется
только руками.

Сначала: `npm run build`, `npm run lint`, `npm test` — все три должны быть
зелёными. Потом `npm run dev` и <http://localhost:3000>.

## Сценарий

Проходите подряд; в скобках — что должно произойти.

**Картинки**
1. Перетащите картинку в окно (появляется по центру, вписана в экран).
2. Потащите её мышью (двигается, не выходит за края).
3. Колесо над картинкой (масштабируется, пропорции целы).
4. Средняя кнопка (появляется копия).
5. Удалите оригинал правой кнопкой (копия остаётся видимой — это проверка
   реестра object URL).
6. `↑` и `↓` (над картинкой растёт и падает счётчик здоровья; на нуле картинка
   бледнеет).

**Режимы и оверлеи**
7. `B`, затем перетащите картинку (она становится фоном, рамка режима гаснет).
8. `L`, затем картинка (разворачивается во весь экран, уходит под токены).
9. `M` (сетка), `'` (эйдос) — и обратно.

**Рисование**
10. `D` (появляется панель кисти), выберите кисть, проведите линию.
11. Смените цвет, размер, прозрачность — линии соответствуют.
12. Ластик стирает; корзина очищает холст.
13. Закройте панель кистью `D` и потащите картинку (canvas не перехватывает
    мышь, когда инструмент не выбран).

**Локации**
14. `PageDown` (панель локаций).
15. «+ Add new», имя, `Enter` (локация создана и стала активной, сцена пустая).
16. Наполните вторую локацию картинкой и штрихом.
17. Переключитесь на первую (вернулись её картинки, фон и рисунок — не второй).
18. Переименуйте локацию карандашом, `Enter`.
19. Во время набора имени нажмите пробел и буквы (кубики не появляются, режимы
    не переключаются — это проверка `isInputActive`).
20. Удалите одну локацию, подтвердите (исчезла; соседняя цела; удалить
    последнюю нельзя — кнопка неактивна).

**Кубики**
21. `1`–`6` (добавляются кубики), клик по кубику и пробел (бросок), правая
    кнопка (убирается).

**Сохранение**
22. F5 (всё вернулось: картинки на местах, фон, рисунок, список локаций,
    активная локация).
23. Измените размер окна (рисунок не исчез, картинки остались в пределах экрана).

**Консоль**
24. В консоли браузера нет ошибок.

## Сброс состояния

Приложение помнит всё между запусками. Чтобы начать с чистого листа, выполните
в консоли браузера:

```js
localStorage.clear();
indexedDB.deleteDatabase('kapkin-viewer');
location.reload();
```

## Что посмотреть в DevTools

- **Application → Local Storage**: ключи `files-<layerId>` и `background-<layerId>`
  только для существующих локаций.
- **Application → IndexedDB → kapkin-viewer → images**: после удаления локации не
  должно остаться ни её картинок, ни ключа `<layerId>-canvas`.

Если после нескольких переключений локаций в IndexedDB копятся записи, которых
не видно на сцене, — данные не убираются при удалении; смотрите скилл
`layer-state`.
